Modern API-First Architecture

By migrating the dashboard away from Streamlit into a dedicated frontend, OptiFlow AI splits computation and visualization. The web dashboard communicates with a high-performance Python FastAPI service to load YOLO, run tracking, and report progress asynchronously.

  • Async Processing: Long-running tasks run in background threads without blocking client requests.
  • Lightweight Client: Frontend runs entirely on static HTML/CSS/JS with smooth animations.
  • Scale Ready: The Python backend can be hosted on GPU clusters while the frontend is served via CDN.

Colab Training Blueprint

# Instantiate and train model
from ultralytics import YOLO

model = YOLO("yolov8n.yaml") # Load architecture

model.train(
    data     = "dataset/data.yaml",
    epochs   = 40,
    imgsz    = 640,
    batch    = 16,
    device   = "cuda",
    patience = 10,
    save     = True
)

# Validate results
metrics = model.val()
print(f"mAP50     : {metrics.box.map50:.3f}")
print(f"Precision : {metrics.box.mp:.3f}")
print(f"Recall    : {metrics.box.mr:.3f}")

Building Smart Infrastructure for Tomorrow

OptiFlow AI is a high-accuracy, edge-compatible traffic analysis system designed to integrate directly with traffic lights and municipal cameras. By detecting vehicle counts, identifying classifications, and outputting live telemetry, OptiFlow AI helps traffic grids respond dynamically to real-world congestion.

Model Information

Our model is built on top of YOLOv8 (You Only Look Once), a state-of-the-art object detection model. We fine-tuned the model on a custom traffic dataset spanning 4,000 annotated images of vehicles, including challenging weather, shadow, and nighttime conditions.

Deployment File: model.pt / best.pt (Approx. 6.2MB, FP16 optimized for CPU and CUDA execution).

API & Decoupled Architecture

Moving from a Streamlit script to a modern client-server architecture eliminates the computation bottleneck. The FastAPI Python server operates strictly on model inference and analytics payload delivery. This enables frontends to be rich, responsive, and deployable on edge browsers or mobile tablets.
